# 📚 Library Management System

A Library Management System developed using Java and Hibernate ORM to perform full CRUD (Create, Read, Update, Delete) operations for managing library records.
The project demonstrates how to integrate Hibernate with Java applications and manage database sessions using a HibernateUtil class.

This system helps manage library resources such as books and users efficiently through a structured backend architecture.

## 🚀 Features

- ➕ Add new books to the library

- 📖 View available books

- ✏️ Update book details

- ❌ Delete books from the system

- 🗄️ Database operations using Hibernate ORM

- 🔄 Session management using HibernateUtil

## 🛠️ Technologies Used

- Java

- Hibernate ORM

- MySQL / Relational Database

- JDBC

- IntelliJ IDEA

## 📊 CRUD Operations

### Operation	Description
- Create - Add new books to the database
- Read   -  View all books
- Update - Modify book details
- Delete - Remove books from the library

## 🧠 Learning Objectives

This project demonstrates:

- Using Hibernate ORM for database interaction

- Implementing CRUD operations in Java

- Managing Hibernate sessions with HibernateUtil

- Structuring a Java backend application
